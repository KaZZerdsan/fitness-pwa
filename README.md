# Тренажёрка 🏋️

Офлайн-PWA для отслеживания силовых тренировок и медицинских показателей.
Без сборки и зависимостей: чистые HTML/CSS/JS. Все данные хранятся локально
(IndexedDB) — сервер и интернет не нужны.

## Возможности

- **Упражнения** — справочник с названием и ссылкой на видео.
- **Тренировки** — шаблоны из блоков-суперсетов: блок содержит несколько
  упражнений (у каждого свои вес/повторения/темп), у блока — число кругов
  и отдых между ними. Темп — 4 фазы: опускание — пауза — поднятие — пауза.
- **Выполнение** — упражнения блока проходятся кругом друг за другом,
  после последнего — отдых и следующий круг; круговой таймер отдыха
  (+15 сек, пропустить, звук и вибрация), Wake Lock, возобновление
  после закрытия приложения.
- **Итоги** — факт по каждому упражнению и кругам рядом с планом, живые
  отклонения (Δ), необязательные калории и средняя ЧСС.
- **История** — завершённые тренировки «план → факт», статусы, «Повторить»
  (копия со статусом «создана»), график прогресса по упражнению.
- **Показатели здоровья** — справочник анализов (название, единица, норма),
  записи с датой, подсветка значений вне нормы, превью-карточка под скриншот,
  выгрузка CSV / копирование текста, график динамики по анализу.
- **Резервная копия** — экспорт/импорт всех данных в JSON.

## Запуск локально

Service Worker (офлайн) работает только по http(s), поэтому нужен любой
статический сервер:

```bash
node tools/serve.js 8123
# или: python -m http.server 8123
```

Открыть http://127.0.0.1:8123

## Установка на телефон (когда будет хостинг)

1. Выложить папку `fitness-pwa` целиком на любой HTTPS-хостинг:
   - GitHub Pages, Netlify Drop (drag&drop), Vercel и т.п.
2. Открыть ссылку на телефоне, добавить на главный экран
   («Установить приложение» / «На экран “Домой”»).
3. После первой загрузки приложение полностью работает без интернета.

## Размещение (позже)

Папка самодостаточна: корень = `fitness-pwa/`. Ничего собирать не нужно.
При изменении файлов поднимите версию кэша (`VERSION` в `sw.js`),
чтобы у установивших приложение обновился кэш.

## Структура

```
fitness-pwa/
  index.html            — оболочка и навигация
  manifest.webmanifest  — PWA-манифест
  sw.js                 — офлайн-кэш (service worker)
  css/styles.css        — тёмная тема, mobile-first
  js/
    db.js               — IndexedDB (4 стора: exercises, workouts, analyses, records)
    util.js             — форматирование, тосты, звук, графики
    app.js              — hash-роутер
    workout-ops.js      — жизненный цикл тренировки (старт/отмена/копия)
    views-home.js       — главная: активная / предстоящие / бэкап
    views-exercises.js  — справочник упражнений
    views-workouts.js   — список, редактор шаблона, просмотр план→факт
    views-session.js    — выполнение + таймер отдыха + итоги
    views-history.js    — история + прогресс по упражнению
    views-health.js     — показатели: записи, анализы, превью, выгрузка
  tools/
    serve.js            — локальный статический сервер
    gen-icons.js        — генератор PNG-иконок (node tools/gen-icons.js)
```
